BBOMS - BIGBREW OPERATIONAL MANAGEMENT SYSTEM
FULLY UPDATED XAMPP TEST BUILD

THIS LOCAL INSTALLATION NOW USES MYSQL 8 ON PORT 3307.
Read MYSQL8_MIGRATION.md before following the generic fresh-install steps below.
After reboot, start Apache and run scripts\start_mysql8.ps1 from PowerShell.
Preserve config.local.php: it contains the dedicated database account credentials.

1. Back up your existing C:\xampp\htdocs\bigbrew folder if present.
2. Extract the included bigbrew folder to C:\xampp\htdocs\
3. Start Apache + MySQL inside XAMPP Control Panel.
4. Open http://localhost/phpmyadmin/
5. Create a database named bboms (utf8mb4_unicode_ci).
6. Open the database -> Import -> Choose C:\xampp\htdocs\bigbrew\database.sql -> Go.
   The import creates the four required BBOMS tables AND the two demo users.
7. Open http://localhost/bigbrew/

DEMO MANAGER: username manager / password Bigbrew12345
DEMO STAFF:   username staff   / password Bigbrew12345

If your MySQL root user has a password, edit bigbrew/config.local.php to match.
The config.local.php file is configured for standard XAMPP defaults only.

If you imported an earlier database.sql, you can import demo_users.sql
instead to add the accounts without changing your existing tables.
Existing accounts with the same usernames are NOT modified or reset.

The BigBrew-style cup-and-moustache mark is bundled locally at
public/assets/bigbrew-icon.svg and bigbrew-icon.png, including a favicon.

LOCAL TEST ACCOUNTS ONLY. Remove the demo users and replace the database
